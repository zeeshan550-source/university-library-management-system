# University Library Management System

## Introduction
The University Library Management System (LMS) is designed to manage library activities digitally.

## Objectives
- Manage library books.
- Manage student membership.
- Handle book borrowing and returning.
- Allow book reservations.
- Track overdue books.
- Send overdue notifications.

## Project Scope
This project focuses on analysing, specifying, modelling, and designing a Library Management System.
